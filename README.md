# AI Mutual Fund Advisor & Portfolio Analyzer

## Overview

AI Mutual Fund Advisor & Portfolio Analyzer is a full-stack web application designed to help investors make informed mutual fund investment decisions.

The platform analyzes user portfolios, investment goals, risk appetite, and investment duration to provide personalized mutual fund recommendations, SIP planning, portfolio insights, and AI-powered guidance.

---

## Problem Statement

Many investors choose mutual funds without proper knowledge of risk, diversification, fund overlap, or long-term planning. Existing platforms provide data but often lack personalized insights and recommendations.

This project aims to simplify investment decision-making using AI-driven portfolio analysis and recommendation systems.

## Workflow

1. User creates an account.
2. User uploads or creates a portfolio.
3. User enters:
   - Age
   - Investment Goal
   - SIP Amount
   - Investment Duration
   - Risk Appetite
4. System analyzes:
   - Portfolio allocation
   - Diversification
   - Fund overlap
   - Risk profile
5. AI generates:
   - Mutual fund recommendations
   - SIP suggestions
   - Portfolio health score
   - Investment insights
6. Dashboard displays:
   - Portfolio growth
   - Returns
   - Charts
   - Recommendations
